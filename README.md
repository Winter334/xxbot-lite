# xxbot

一期 Discord 修仙 Bot。

## 本地启动

> 需要 **Python 3.12**。若本机只有 Python 3.11，请先安装 3.12 再创建虚拟环境。

1. 创建虚拟环境并安装依赖：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .[dev]
```

2. 复制 `.env.example` 为 `.env` 并填写 `DISCORD_TOKEN`。
3. 初始化数据库：

```powershell
alembic upgrade head
```

4. 启动 Bot：

```powershell
python -m bot.main
```

## 境界身份组

在服务器内使用 `/领取身份组`，或点击 `/修仙` 主面板的「领取身份组」按钮，按角色**当前大境界**领取身份组，不按小阶段或历史最高境界领取。每次成功领取只保留一个当前大境界身份组，并移除其他可识别的已开放境界身份组，以及管理员通过 `REALM_ROLE_CLEANUP_IDS` 显式指定的旧身份组；其余身份组（包括未配置清理的仙道身份组）不碰。突破或轮回后需要重新领取，不做自动同步。

默认按当前服务器身份组的**精确名称**匹配，当前 Bot 大境界及默认匹配名称如下（配置模板的注释中也列出了此表）：

| `realm_key` | 身份组名称 |
|---|---|
| `lianqi` | 炼气 |
| `zhuji` | 筑基 |
| `jiedan` | 结丹 |
| `yuanying` | 元婴 |
| `huashen` | 化神 |
| `lianxu` | 炼虚 |
| `heti` | 合体 |
| `dacheng` | 大乘 |
| `dujie` | 渡劫 |
| `weixian` | 伪仙（本服无对应身份组） |

本服不需要配置 `weixian`。省略此项后仍遵循同名匹配规则，无「伪仙」身份组时会提示缺少身份组，不自动代领渡劫或仙道身份组，也不会修改玩家已有身份组。仙道境界尚未在 Bot 开放，不能在 `REALM_ROLE_IDS` 中配置领取。

身份组有装饰字符或使用不同名称时，可在 `.env` 中设置可选的 `REALM_ROLE_IDS` JSON 对象，按境界覆盖。以下 ID 为虚构示例，必须替换为**当前服务器中已存在的身份组 ID**；无需给整段 JSON 再加引号：

```dotenv
REALM_ROLE_IDS={"lianqi":"10001","zhuji":10002}
```

- 已配置境界以 ID 为准，不回退同名匹配，即使该 ID 在当前服务器不存在；未配置境界仍精确同名匹配。
- 名称匹配遇到重复名称时拒绝含糊选择，可用 ID 明确指定目标身份组。
- 配置为空时全部按名称匹配。境界 key 只接受上表中的已开放境界，ID 只接受正整数或十进制数字字符串，同一 ID 不得绑定多个境界；非法配置会阻止启动并提示错误。
- Bot 不会自动创建身份组。修改配置后重启 Bot，新斜杠命令会在启动时同步。

接管旧 Bot 遗留的身份组时，可额外设置 `REALM_ROLE_CLEANUP_IDS`。它是**仅用于清理的身份组 ID 列表**，可以填写真仙、金仙、太乙玉仙、大罗金仙等尚未开放的境界组，也可以填写旧名称或带装饰字符的组。以下 ID 为虚构示例，请替换为需要清理的真实 ID，无需给整段 JSON 再加引号：

```dotenv
REALM_ROLE_CLEANUP_IDS=["20001","20002","20003","20004"]
```

- 留空或 `[]` 不额外清理；只接受正整数或十进制数字字符串，重复 ID 自动去重，非法配置会阻止启动。
- 仅在玩家领取身份组时检查并移除其持有的列表内身份组，不会批量修改全服成员。不在当前服务器或玩家未持有的 ID 会跳过。
- 当前应领取的身份组即使出现在清理列表中也会保留。列表不用于发放身份组，也不会开放对应境界。
- 先成功发放当前境界身份组，再清理旧组；已持有当前组时仍会清理。当前组缺失或发放失败时不清理，清理失败可再次领取重试。
- 修改配置后重启 Bot，让玩家重新领取即可生效。

Bot 需要「管理身份组」权限，且 Bot 的最高身份组必须高于所有待添加或移除的身份组。不支持托管身份组、`@everyone` 或带管理、审核日志、提及所有人等敏感权限的身份组。领取结果仅向操作者发送私人提示，不在群内通知。
