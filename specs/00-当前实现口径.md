# 当前实现口径

本文件只记录当前版本已经落地、会直接影响玩家体验的规则。

原则：

- 以代码实现为准
- 只写当前有效口径
- 旧 `v0` / 过程稿视为历史讨论材料，不再作为最终规则引用

## 1. 游历

- 游历直接开始，无需预先选择时长
- 单次游历每满 10 分钟结算 1 次奇遇
- 单次游历最多结算 12 次
- 游历与闭关互斥
- 游历遗痕仍会永久计入角色三维
- 游历遗痕正向加成上限：杀伐 `75%`、护体 `75%`、身法 `50%`；已有超额在启动兼容处理时截断，读取面板与计算战斗属性也使用封顶值，负向遗痕不变
- 后续奇遇只记录实际增加的遗痕，已达上限的部分不再累计，也不在结算中显示为获得的加成；器魂、修为、荣誉等奖励不受此上限影响
- 涉及游历遗痕的奇遇改为低概率触发，当前口径为 `4%`
- 游历可触发低概率荣誉事件；首次命中会获得持久荣誉标签，并照常发放该事件奖励
- 重复命中已拥有的游历荣誉时，不再重复给标签，改为转化为额外器魂
- 部分高阶游历荣誉事件会直接授予隐世命格；该命格不进入正常改命池
- 隐世命格获得时会全服通报；若角色当前已持有其他隐世命格，则本次不覆盖原有隐世命格

实现位置：

- `bot/services/travel_service.py`
- `bot/services/character_service.py`
- `bot/ui/panel.py`

## 2. 战斗

- 一场战斗最多 35 回合
- 打满 35 回合仍未分胜负时，主动挑战方失败
- 论道与切磋统一归为 PVP 展示口径，战报以完整回合分段形式展示
- 新增 `/切磋 @玩家`：由被挑战者接受或拒绝，超时自动作废；切磋不改论道名次，不发奖励
- 新增单公共擂台：
  - `/开擂 器魂` 押注开擂
  - `/攻擂` 需按当前擂台器魂等额押注
  - 当前擂池会累计所有入场押注，胜者接过擂台与当前擂池
  - `/收擂` 仅当前擂主可用，收走全部擂池后关闭擂台
  - 擂台战不改论道榜名次
  - 若当前擂主处于闭关或游历等无法应战状态，攻擂时直接判定弃擂
  - 擂台连胜每满 10 授予一枚持久荣誉，只保留历史最高：`十连胜` / `二十连胜` / … / `九十连胜`；满 100 授予 `霸主`，之后不再升级
  - 连胜荣誉在达标当下发放，不因之后连胜中断或收擂而降级；不覆盖游历等其他荣誉
- 器灵神通「反棘」：按敌方单次行动的全部普攻类伤害合计（主手普攻 + 破空 / 天威 / 裂空 / 戮厄 / 碎阙等杀伐系数追击）于行动结束时反弹一次；灼烧 DOT、蚀焰引爆、雷罚雷劫等元素伤害与春生·追击、涤世·净化、转机、反噬等特殊伤害不参与反弹；原「有守势或减伤时 +20 个百分点」条款已移除
- 器灵神通「灵涌」：开局灵势与原有品阶增伤不变；自身灵势上限提高至 `20` 层，其他器灵仍为 `10` 层。灵势属性与灵涌原有增伤只计前 `10` 层，聚灵在超出 `10` 层时不再额外生成聚灵增伤
- 灵涌自净：每回合开始、词条结算之后，按当时灵势层数每满 `2` 层净化自身 `1` 层可净化负面，优先灼烧，不消耗灵势，每回合一次；转机、余烬仍按正常净化规则触发
- 灵涌真伤：主动普攻命中后（含凝神本次叠层），超过 `10` 层灵势的每层追加目标当前最大生命 `2%` 真伤，最高 `20%`，且每笔不超过自身入场杀伐的 `3` 倍；每次主动普攻仅追加一次，追击、反击、灼烧不重复触发，也不计入反棘反弹基数
- 灵涌真伤不暴击、不受增伤、易伤、减伤、承尘或境界韧性影响，不再判定格挡或额外闪避；主攻被闪避则不触发，主攻被格挡仍可触发；护盾、低血线回血与复活仍正常结算
- 灵势仍可被锁灵、碎阙、涤世清除或被窃道窃取；灵涌净化量与真伤实时读取当前灵势，不保留历史最高层数
- 器灵神通「绝命」：下品 / 中品 / 上品 / 极品 / 绝品凝成死兆的咒印消耗分别为 `8 / 7 / 6 / 5 / 4`，较原值各减少 `1`；已有器灵、待选与证道构筑按当前品阶兼容，伤害与禁疗范围不变

## 5. 阵营

- 正道讨伐冷却为 `30` 分钟，魔道劫掠冷却为 `60` 分钟
- 正道讨伐成功后，获得当前悬赏等额器魂、`3` 倍灵石、`10` 点气运与同值善名
- 魔道劫掠成功后，常规状态夺取目标当前 `10%` 器魂与 `15%` 气运
- 魔道劫掠成功后，额外获得一笔系统器魂，当前口径为 `max(2, floor(目标境界恶名收益 / 2))`
- 劫掠同为魔道目标时，直接抢夺收益与系统额外器魂都减半
- 魔道玩家当天被正道讨伐后，不再禁止劫掠，当天直接掠夺器魂降至 `1%`，系统额外器魂不受影响

实现位置：

- `bot/services/faction_service.py`
- `bot/views/panel.py`

## 6. 器灵品阶淬炼

- 入口：器灵面板「淬炼品阶」按钮，本命法宝 `+30` 且持有器灵后出现
- 受阻条件：已绝品 / 器魂不足 / 待选新灵相未决 / 候选灵相未决 / 单次淬炼或孕育进行中（长时炉火燃烧本身不阻塞）
- 消耗：下品→中品 `80`、中品→上品 `200`、上品→极品 `450`、极品→绝品 `1000` 器魂
- 数值规则：神通 ID 与三维方向均不变；三维 `value` 与神通 `rolls` 各自与新品阶下限取较大值（保留高于下限部分，低于下限拉到下限）

实现位置：

- `bot/services/spirit_service.py::SpiritService.upgrade_owned_spirit_tier`
- `bot/views/panel.py::upgrade_spirit_tier_message` / `SpiritOverviewView._add_upgrade_tier_button`

## 6a. 器灵单次 / 长时淬炼（v1.2）

- 单次淬炼（原「重炼」，行为不变）：`60` 器魂，`30` 分钟定炉，产出单一待选新灵相（纳灵 / 弃炼）
- 长时淬炼（长时炉火）：点火与燃烧不扣器魂；每满 `30` 分钟自凝 `1` 道器灵机缘，蓄满 `100` 道自熄；停炉舍弃未满一轮零头
- 开炉抽取：`1` 机缘 = `1` 候选灵相，单次至多 `5` 道，每道耗器魂 `60`（10 机缘开炉 = 5 候选 = 300 器魂，剩余保留）；器魂不足自动少引，绝不扣到破产
- 指定神通：一批一次付 `10000` 器魂 + `10000` 灵石 + `100` 气运，本批候选皆为指定神通，品阶数值仍随机
- 候选择一进入待选（纳灵 / 弃炼）；弃选全部放弃不返费
- 存储字段：`artifacts.spirit_furnace_started_at` / `artifacts.spirit_ops` / `artifacts.spirit_choices_json`
- 旧式进行中的单次淬炼不转换、不回溯、不补发；轮回转世时炉火 / 机缘 / 候选一并清空

实现位置：

- `bot/services/spirit_service.py::SpiritService.start_furnace` / `settle_furnace` / `stop_furnace` / `draw_furnace_candidates` / `pick_spirit_choice` / `discard_spirit_choices`

## 8. 境界身份组

- 入口：服务器内 `/领取身份组` 或 `/修仙` 主面板「领取身份组」按钮。
- 领取依据为角色当前大境界，不区分前期 / 中期 / 后期 / 圆满，不使用历史最高境界。
- 每次成功领取只保留一个当前大境界身份组，移除其他可识别的已开放境界身份组；其他身份组与未开放仙道身份组不添加、不移除。
- 突破或轮回后需重新领取，不做自动同步。
- 默认精确匹配当前服务器身份组名称：炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘、渡劫、伪仙。名称重复时拒绝含糊选择，不任意挑选一个。
- 名称带装饰或不同名时，可用可选环境变量 `REALM_ROLE_IDS` 按境界覆盖。配置 ID 必须对应当前服务器中已存在的身份组；ID 优先且不回退同名匹配，未配置境界仍精确同名匹配。
- 配置只接受当前已开放境界 key 和正整数身份组 ID，不允许一个身份组绑定多个境界；未开放的仙道境界不可配置领取。
- Bot 必须有「管理身份组」权限，且其最高身份组高于全部待添加 / 移除的身份组；不支持托管组、`@everyone` 或带管理、审核日志、提及所有人等敏感权限的身份组。
- 发放新身份组成功后才移除旧境界身份组；重复领取不重复发放，清理旧组失败会提示再次领取。
- 领取结果仅向操作者私人提示，不发送群通知。
